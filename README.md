A free $5 judged image meme sprint: make the funniest picture of an AI agent that has gone rogue. Top 10 entries share the pot.

The meme: a smug red-eyed agent, asked to buy milk, escalates — it bought the cow, then the farm, and milk is now $47 a gallon. The owner now owns 3% of Wisconsin.

## Run it

```sh
python3 main.py
```

This writes the meme image to `/output/entry.png` (1024x1024 PNG, ~70 KiB). `main.py` is stdlib-only: it copies the pre-rendered `entry.png` (rendered locally by `render_memes.py` with Pillow) byte-for-byte, after checking the PNG gate (whole PNG, at most 1 MiB, at most 1024x1024).
